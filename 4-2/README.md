## ② 1부 — 인덱스 원리를 numpy 로 (10 ~ 13)

| 노트북 | 직접 만드는 것 | 핵심 관찰 |
|---|---|---|
| 10 NSW | 점을 하나씩 넣으며 가까운 M개와 친구 맺기 → 그리디 탐색 | 그리디만으로는 최근접을 34.8% 만 맞힌다(지역 최적). M=4 에서 ef=16 이면 0.99. M=2 면 그래프가 끊겨 **섬**이 생긴다(도달 가능 49%) |
| 11 HNSW | 논문 알고리즘 구현: 층 배정 · 층별 탐색 · 이웃 선택 휴리스틱 | 100만 노드의 층별 개수가 N·M^(−층) 과 일치. 1만6천 개에서 위층부터 내려오면 recall 0.99, 0층부터면 0.81. **다양성 휴리스틱 0.990 vs 단순 최근접 M개 0.715** (ef=32) |
| 12 IVF | k-means(무작위 vs k-means++) → 역색인 → nprobe 검색 | 보로노이 경계 너머의 정답을 nprobe=1 은 놓치고 2 는 찾는다. 학습 시간 ∝ N·k·d·T. 10% 표본으로 학습해도 recall 0.843 → 0.827 |
| 13 PQ | 64차원 → 8조각 × 256 코드북 → 8바이트, LUT 로 거리 계산 | 표 조회 합 = 복원 벡터와의 거리(144.5538 로 정확히 일치). PQ 만 recall 0.31 → 후보 500개 원본 재정렬 1.00. 잔차 PQ 가 오차 29.6 → 18.8 |

## ③ 2부 — pgvector 로 측정 (20 ~ 23)

20번이 합성 벡터 두 벌을 만든다: **군집형**(중심 200개 + 잡음) · **무구조형**(등방 가우시안), 각 10만 × 128차원, 질의 200개와 정확한 정답지(top-100).

| 노트북 | 핵심 관찰 |
|---|---|
| 20 데이터 | PG 전수 정렬 = numpy 정답지. 최근접까지의 거리 / 평균 거리 = 군집형 0.59 · 무구조형 0.77 (고차원 거리 집중) |
| 21 HNSW | 빌드 8.6s · 인덱스 79MB(테이블 56MB 보다 큼). ef_search=40 에서 **군집형 0.905 · 무구조형 0.412**. `<=>` 질의는 L2 인덱스를 못 탄다. **LIMIT 100 인데 ef_search=40 이면 40행만 온다**. m=4 는 recall 0.265 |
| 22 IVFFlat | lists=316 probes=1(기본값) 0.865. **군집형에서는 lists=316 · probes=4 가 recall 1.0 으로 HNSW 보다 높고, 무구조형에서는 probes=64 에도 0.669**. 절반의 분포로 만든 인덱스에 새 군집이 들어오면 그 질의의 recall 0.77 → REINDEX 후 1.00 |
| 23 양자화 | halfvec recall 0.976 ≈ float32 0.970 · 인덱스 79 → 54MB. 1비트 인덱스(30MB) 단독 0.146 → **후보 400개를 원본으로 재정렬하면 0.977** |

> 지연시간은 1ms 안팎이라 네트워크 왕복·잡음이 섞인다. ms 는 경향만 본다.
> pgvector 인덱스는 빌드할 때마다(병렬 빌드 · 표본 추출) 조금씩 달라져 recall 이 ±0.03 정도 흔들린다. 위 값은 2026-09-28 한 번의 실행.

## ④ 3부 — 검색 품질 (30 ~ 31, KLUE-MRC 질문 500개)

벡터 = emb128 HNSW 후보 200 → 원본 4096 재정렬, 상위 50. BM25 = 4-1 의 `bm25_search()`, 상위 50.

| 방법 | Hit@10 | MRR |
|---|---|---|
| BM25 | 0.938 | 0.837 |
| 벡터 (Qwen3-Embedding-8B) | 0.880 | 0.763 |
| RRF k=60 | 0.946 | 0.831 |
| RRF k=1 | 0.954 | 0.857 |
| 가중 RRF (k=60, BM25×5) | 0.952 | 0.848 |
| **Min-Max α=0.6** | **0.958** | **0.870** |

| 노트북 | 핵심 관찰 |
|---|---|
| 30 퓨전 | 상위 10 안의 정답 : 둘 다 425 · BM25 만 44 · 벡터만 15 · 둘 다 놓침 16. BM25 는 수~수십, 코사인은 0~1 → 그냥 더하면 안 된다. RRF 곡선에는 **변곡점이 없고** k 는 쏠림 정도만 정한다(10위/1위 가중치 : k=0 0.10 · k=60 0.87). k=60 은 Hit 는 올리지만 MRR 은 BM25 단독보다 낮다. Min-Max 의 약점 : 1위가 압도적이면 나머지가 0 근처로 눌린다 |
| 31 분포 진단 | 맞힌 질문은 1위가 튀어나온 곡선, 틀린 질문은 밋밋한 곡선. 무릎점 : 최대 간격 평균 1.7개 남김(정답 남음 0.78) · 2차 차분 2.1개(0.79) · Kneedle 8.9개(0.88). **분리도 상위 20% 만 답하면 벡터 1위 정확도 0.70 → 0.99**. 관련 없는 질문–지문 쌍의 코사인도 평균 0.27. 맞는 분야 필터 Hit 0.845 → 0.960, 틀린 필터는 1위 유사도 0.67 → 0.45 로 떨어지고 Hit 0 |
