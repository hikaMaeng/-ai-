### P1 — 이해도 개선

1. **용어 풀이** : 첫 등장 용어마다 한 줄. 8-1은 정책 · JSON Schema · FSM · logit 마스킹 · SFT · RLVR · lost in the middle · pass@k · 임베딩 · JSON-RPC, 8-2는 instruction hierarchy · sycophancy · confused deputy · exfiltration · zero-click · ASCII smuggling · CaMeL.
2. **도해 추가**(신설이므로 승인 필요) :
   - 8-1 : 에이전트 루프 · 도구 호출 왕복 시퀀스 · 워크플로우 vs 에이전트 · 메모리 계층 · 멀티에이전트 4패턴 · MCP 구성도 · 복리 오류 곡선(`0.95^n`)
   - 8-2 : 스킬 3단계 로딩 · 모델-스크립트-상태파일 시퀀스 · 확장 수단 4종 비교 · Lethal Trifecta 벤다이어그램 · 다층 방어 · Dual LLM
3. **구체 예** : 8-1 도구 설계 · 메모리 · 멀티에이전트에 실제 실행 장면 한 개씩, 8-2 보안 구간에 공격 → 차단 한 건씩.
4. **고난도 장표 분리** : 8-1 「도구 스키마와 구조적 출력」(제약 디코딩)은 「왜 필요한가」 중심으로 낮추고 세부는 보충으로.
